# BartonDesk roster (mirror)

GitHub Pages mirror for BartonDesk: the signed staff list, the signed update document and the current Windows downloads. See README.md.

## Rules
- **Don't edit anything here by hand.** BartonDesk Owner on the owner PC writes, commits and pushes every file. A hand edit breaks signatures or hashes, and customer apps then reject the list or update.
- Only README.md and CLAUDE.md may be changed manually.
- Run `git pull` before touching the repo. It's cloned on more than one machine.
